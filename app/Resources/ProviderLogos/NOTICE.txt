JR-Bar provider marks: sources, licences and trademarks
=======================================================

JR-Bar draws each AI coding provider's own mark (Claude, OpenAI/Codex,
Gemini, Grok, Devin, Cursor and the rest) so you can tell at a glance whose
session, quota or ask you are looking at. The marks ship inside the app as
vector path data (app/Sources/JRBarUI/ProviderLogoData.swift, generated by
scripts/gen_provider_logos.py from the SVG files beside this notice). JR-Bar
never downloads them.

Trademarks. Every mark is a trademark of its owner: Anthropic (Claude),
OpenAI (OpenAI, ChatGPT, Codex), Google (Gemini, Antigravity), xAI (Grok),
Cognition (Devin), Anysphere (Cursor), Amazon Web Services (Kiro), Nous
Research (Hermes Agent), the OpenCode, Pi, OpenClaw and T3 Code projects,
and so on. JR-Bar uses each one only to name the provider it stands for.
JR-Bar is not affiliated with, sponsored by or endorsed by any of them, and
none of the marks is part of JR-Bar's own name, icon or branding.
