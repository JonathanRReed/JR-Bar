What this sheet is

  • The single list of sizes, colours, radii and timings every mockup on this site uses. The build would ship them as JRType, JRColor, JRRadius, JRSpace and JRMotion in Swift.
  • Type follows the macOS text styles, with one rule added: nothing below 11 pt, even captions and badges.
  • Colours are semantic. A view asks for .stale or .ask, never for a hex value. Each one has a light and a dark value, shown side by side below.
  • Stale is grey with an age. Orange means only one thing: an agent asks.
  • Motion has four durations. Click any motion card to replay it.

The make fast check

  • Fails on a literal .font(.system(size:)), a Color(red:…) or hex, a cornerRadius number, or an .animation(…duration:) number outside the token files.
  • Fails on block characters (▁▂▃▄▅▆▇█, ░▒▓) in any view string.
  • An exception needs a one-line // token-exempt: reason comment, and the check lists every exemption.

Audit findings fixed

  • Tiny fonts → an 11 pt floor
  • One-off colours → named, semantic colours only
  • Stale as warning → a grey token, kept apart from Ask
  • Red selected ring → selection is always the accent
