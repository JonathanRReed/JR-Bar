Key choices

  • Content is drawn on the first frame. The panel arrives at 50% opacity and 98% scale with everything in it already laid out, so you can read it while it settles. Today the text fades in only after 120 ms of movement.
  • Entrances are 140 ms with a fast-out curve cubic-bezier(.2,.8,.2,1). Exits are 100 ms, because closing should feel instant.
  • The notch grows over 250 ms with no overshoot. Its content keeps its final size and the black shape reveals it, so nothing reflows mid-motion. Today's 450 ms spring bounces, then fades the text in.
  • State changes in place (Working → Done) crossfade in 160 ms and never move the row.
  • Reduce Motion: every entrance becomes an 80 ms fade, with no scale and no size morph.

The numbers

  • Panel open: 260 → 140 ms, readable at 120 → 0 ms
  • Panel close: 260 → 100 ms
  • Notch open: 450 → 250 ms, readable at 300 → 0 ms
  • Notch close: 350 → 180 ms
  • Row state change: 300 → 160 ms

Audit findings fixed

  • Slow, floaty panel and notch → Raycast-speed entrances with content on the first frame
  • Notch bounce → a settled curve with no overshoot
