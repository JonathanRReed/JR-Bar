Key choices: What's New

  • One feature leads, with a moving picture (an agent group folding open), and four smaller ones sit under it. Hierarchy replaces the old flat list of equal bullets.
  • Every feature has a "Show me" link that opens the exact place: the panel, Studio, Settings › Providers.
  • It opens once after an update, as a normal window, never over an ask. Esc or Continue closes it. Full notes live one click away.

Key choices: Setup

  • A step list on the left shows where you are and what is optional. Back and Continue sit in one footer; ↩ continues, ⌘[ goes back.
  • Providers lists only what is on this Mac. The rest is one quiet line, not ten disabled rows.
  • Usage sources start off. Anything that would leave the Mac (an account API, the CLI fallback) has its own switch and says what it reads. Local sources need no switch.
  • Asks shows the real notch card and states the rule: only you answer an ask.
  • Lights is optional and skippable; with nothing connected it says so in one line.

Audit findings fixed

  • Flat What's New → a lead feature with art, then a grid
  • Flat Setup → numbered steps with done, current and optional states
  • Tiny fonts → title 22 pt, lede 15 pt, body 13 pt

Open questions

  • Which feature should lead 0.10.0: agent groups, Studio, or "lighter and faster"?
  • Can What's New quote the measured CPU and memory numbers once the 24 hour run is done, or should it stay in words?
  • Shortcuts: are ⌥⌘J (panel) and ⌥⌘L (Studio) free on your Mac, or do you want others?
  • Should Setup run again for a new provider (a short sheet), or should that live only in Settings?
  • If Track is turned off in Setup, should the hook be removed from that provider's config, or only ignored?
