Design review

Eight surfaces, each a single self-contained page. Every page has a notes column with the key choices, the audit findings it fixes, and questions for you. Press T on any page to switch appearance.

SnappyContent is on screen from the first frame. Entrances take 140 ms, exits 100 ms, the notch 250 ms.
HonestStale is grey with its age. No quota source says so. Orange only means an agent asks.
NativemacOS 26 sidebars, grouped forms and glass. Type never goes below 11 pt. The menu bar icon stays as it is.
