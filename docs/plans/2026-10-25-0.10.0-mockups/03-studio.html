Key choices

  • Studio holds everything about light. One preview stays pinned at the top on every page, so a change shows at once. It draws the 8 LEDs and the Screen Bar from the same colours, on a grey stage with a rimmed device, so the off LEDs never sink into the background.
  • Preview as if sets the situation: 1, 2 or 3 providers, or an ask. With one provider you see that provider's own animation. With two or more you see the global Mix.
  • The What plays panel spells out the result, including any place where a combination plays something else, for example the one-LED PulseDot. Nothing falls back silently.
  • Mix has three groups. Share mixes give each provider a share and its own animation. Mix animations are built for several colours. Calm holds the strip still. Each card has a live preview in the scenario's colours, and the selected card has an accent ring and a check, never red. Blend appears in exactly one place, under Everyone.
  • Each provider appears once on the Providers page, with its animation, colour, speed and a live mini strip. On Automatic, Ember plays as a layer. When you choose an animation, it always plays.
  • Cues are a layer stack: Ask sits on top and is locked. Celebration, Milestone and Ember each last a few seconds at most. The running animation sits at the bottom.
  • Device overrides are labelled rows (device, what, value). Each row says why the override exists and has a remove button.

Audit findings fixed

  • Studio buried under Settings → its own window, panel button, ⌥⌘L
  • Unbalanced layout, black-on-black preview
  • Duplicated assignments → one row per provider
  • Selected tile ringed red → accent ring and check
  • Blend mode set in three places → once

Open questions

  • Should Split give the most recently active provider the extra LED, or follow the provider order?
  • Should Mix be one global setting, or should each scene carry its own Mix (as shown, since the scene popup changes it)?
  • How long should One at a Time hold each provider: 3 s, or a setting?
  • Should "Also play on the devices" be on by default when Studio opens?
  • Should the Weave and Tide names stay, or would plainer names read better ("Braid", "Waves")?
