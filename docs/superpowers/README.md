Swift app replaced, and the wave planning around it. They were archived on
2026-09-10 and are kept only for provenance. Nothing in the build, the tests or
the release gate reads them.

`src/jrbar/colors.py`, `src/jrbar/virtual_device.py`. Rewrite
`docs/superpowers/…` as `docs/archive/superpowers/…` when you next touch those
